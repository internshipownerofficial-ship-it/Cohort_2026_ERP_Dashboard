Curriculum & Modules

Core training modules with instructional objectives and practical examples.

Module 01 Foundations

Digital Primer

Foundational digital and hardware logic awareness. Focuses on binary logic, digital hardware design principles, basic circuit behavior, and standard conventions used across embedded platforms.

Practical Example:

Using binary logic (0 and 1) or switch states (HIGH and LOW) to blink onboard LEDs and understand voltage levels in digital circuits.

Module 02 Software

Intro to Complete Embedded C Programming

Master writing efficient, hardware-aware C code tailored for microcontrollers and embedded processors. Covers core C syntax, memory management, pointer manipulation, and register-level configuration.

Practical Example:

Direct register configuration and bitwise operations (PORTB |= (1 << 5)) to configure specific Shrike FI pins as inputs or outputs.

Module 03 Tooling

Linux Toolbox

Equip participants with essential command-line tools and development environments required for modern embedded workflows, including shell scripting, process management, and GCC/GDB utilities.

Practical Example:

Using WSL2 and terminal utilities (gcc for compilation, git for repository push, and pytest for automated testing).

Module 04 Integration

Demonstration of Entire Training

Showcase end-to-end integration by bringing together hardware, embedded software, and tooling into a live working prototype. Capstone project deployment using Vicharak hardware.

Practical Example:

Building a smart sensor node or rover-drone prototype running C inference runtimes, debugged in Linux, deployed on Shrike FI.
